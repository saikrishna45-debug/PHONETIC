# Frontend Architecture & Documentation

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Component UI**: Radix UI / shadcn/ui primitives
- **Icons**: Lucide React
- **Client State & API**: Fetch abstraction layer with typed DTOs and mock fallbacks

## Directory Layout
- `app/`: Next.js App Router pages and layouts
- `components/`: UI components categorized by domain
- `lib/`: Utilities, constants, and API client layer
- `types/`: Domain TypeScript interface and type definitions
- `data/`: Mock data for development and demonstration
- `public/`: Static images, icons, and logos
- `styles/`: Global styles and theme configurations
